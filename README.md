 ## Project Overview

 **GreenScape Solutions** is a proposed South African property-maintenance business providing professional property-care services, including:

 - Grass cutting
- Roof washing
- Scheduled property maintenance services

 The website project aims to support the business's digital presence by providing customers with accessible information about the company, its services, pricing, and contact options.

 The broader business vision focuses on:

 - Reliability
- Sustainability
- Local employment
- Quality property maintenance
- Using technology to improve service delivery

 The current prototype is a basic multi-page website developed using **HTML**. It provides the foundation for future improvements using **CSS** and **JavaScript**.



 ## Website Goals and Objectives

 The website is intended to:

 - Increase GreenScape Solutions' brand awareness.
- Generate customer enquiries, quotations, and bookings.
- Build trust by communicating the company's values and sustainability practices.
- Provide customers with clear information about available services.
- Reduce manual enquiries through online quotation and scheduling functionality.
- Support future expansion into other South African cities.
- Improve local visibility through location-focused content and SEO.

 ## Design Direction

 The planned redesign will use a clean, natural, and professional aesthetic that reflects:

 - Landscaping
- Property care
- Reliability
- Sustainability
- Professional service

 ### Colour Palette

 | Colour | Purpose |
| --- | --- |
| **Deep Green** | Primary brand colour |
| **Leaf Green** | Accent colour |
| **Off-White** | Backgrounds and clean spaces |
| **Warm Sand / Beige** | Secondary accents |
| **Dark Charcoal** | Text and contrast |

### Typography

 The website will use:

 - **Headings:** Montserrat or Poppins
- **Body Text:** Inter or Open Sans

 These fonts are intended to provide a modern appearance while maintaining good readability.



 ## User Experience

 The website user journey is designed around a simple process:

